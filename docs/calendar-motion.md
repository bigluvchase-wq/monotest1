# Анимации календаря и исправления переходов

Из присланных примеров Animorio взят порядок движения, реализация самостоятельная на WAAPI без GSAP: мягкое раскрытие единым слоем, акцент дат с событиями, короткий отклик выбранного числа и сдвиг при смене месяца. Покадровое изменение высоты сетки и отдельные анимации каждого дня убраны. Конечная геометрия календаря устанавливается один раз. Исходная поверхность карточки не подменяется и не масштабируется: её фон и скругления сохраняются; через FLIP двигаются только соседние блоки, а содержимое календаря мягко проявляется. Используется существующая структура календарей платежей и напоминаний; окно выбора периода тоже получает раскрытие. Системные iOS-календари внутри native input не заменяются.

Дизайн Моно сохранён. Глубину добавляют статические тени, внутренний свет и тематическая заливка дней с событиями. Новые анимации меняют только transform/opacity; inline-раскрытие сохраняет итоговые размеры без перехода grid-template-rows. При Reduce Motion новые движения отключены. Функции выбора дат, повторов и расчётов не менялись.

В записи с iPhone после раскрытия напоминаний вызывался `focus(id)` с отдельной плавной прокруткой. Теперь этот вход использует только подсветку, без прокрутки; фокус скрываемой исходной карточки снимается, на время перехода отключается scroll anchoring. Непрозрачная растущая подложка полностью удалена: открывается живое содержимое без белого прямоугольника.

После волны сохранения подтверждение больше не закрывается мгновенно: `dismissReceipt` оставляет его в DOM до конца 380-мс ухода и растворения. Форма остаётся недоступной для повторной записи до завершения закрытия.

Проверки: `node --test tests/*.test.cjs`, `tools/verify-reminder-expand.cjs`, `tools/verify-mic-beam.cjs`. Браузерные сценарии проверяют отсутствие прокрутки после раскрытия, очистку при прерывании, темы, календари и плавное закрытие подтверждения. Финальную плавность в WKWebView необходимо проверить на iPhone.

Переход с главной больше не создаёт копию напоминания или главного экрана. За 140 мс растворяется настоящий экран, затем без видимой перестройки меняется маршрут и проявляется список. Поэтому исходная карточка не попадает под стили другой страницы. При прерывании восстанавливаются доступность ввода и прозрачность; автопрокрутки нет.

Переключение корневых вкладок возвращено к реализации из коммита `16cc45e` (до PR №49): прежний сдвиг на ширину экрана и интерактивный свайп. Изменения календаря не затрагивались.
