# Анимации календаря и исправления переходов

Из присланных примеров Animorio взят порядок движения, реализация самостоятельная на WAAPI без GSAP: раскрытие с небольшим масштабом, появление дат по очереди, мягкий акцент дат с событиями, короткий отклик выбранного числа и сдвиг при смене месяца. Используется существующая структура календарей платежей и напоминаний; окно выбора периода тоже получает раскрытие. Системные iOS-календари внутри native input не заменяются.

Дизайн Моно сохранён. Глубину добавляют статические тени, внутренний свет и тематическая заливка дней с событиями. Новые анимации меняют только transform/opacity; существующее раскрытие inline-сетки сохраняется. При Reduce Motion новые движения отключены. Функции выбора дат, повторов и расчётов не менялись.

В записи с iPhone после раскрытия напоминаний вызывался `focus(id)` с отдельной плавной прокруткой. Теперь этот вход использует только подсветку, без прокрутки; фокус скрываемой исходной карточки снимается, на время перехода отключается scroll anchoring. Геометрия раскрытия измеряется после установки контекста позиционирования. Содержимое проявляется раньше, чтобы сократить пустой кадр.

После волны сохранения подтверждение больше не закрывается мгновенно: `dismissReceipt` оставляет его в DOM до конца 380-мс ухода и растворения. Форма остаётся недоступной для повторной записи до завершения закрытия.

Проверки: `node --test tests/*.test.cjs`, `tools/verify-reminder-expand.cjs`, `tools/verify-mic-beam.cjs`. Браузерные сценарии проверяют отсутствие прокрутки после раскрытия, очистку при прерывании, темы, календари и плавное закрытие подтверждения. Финальную плавность в WKWebView необходимо проверить на iPhone.
