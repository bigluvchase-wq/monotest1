# Compact account picker and primary microphone

The home recording-account control keeps its responsive 300px/85vw width and 32px visible height. The selected design uses a thin theme-colored outline, a single account label and a chevron. Its invisible hit extension supplies 44px vertically; the keyboard has enough spacing to avoid overlapping that target.

The existing native select remains a visually hidden compatibility source, excluded from the tab order and accessibility tree. The real button opens a native modal dialog for focus containment, keyboard dismissal and scrolling. Personal and shared account summaries come from the same local sources as Together's native picker. Selections call the existing async select handler, preserving private/shared switching, offline behavior and the recording account. Balances use the finance engine; names and values are escaped. The sheet is busy during a switch and rejects duplicate requests; dismissal does not wait for that request.

The bottom sheet moves up 100% on entry (280ms) and fully offscreen on exit (280ms), through WAAPI transform only. Entry and drag release use the existing ease-out; button/selection exits use a gentler ease-in-out so the downward movement remains visible. The final offscreen frame is held until native close, avoiding a visible snap back. Close button, Escape, backdrop and downward swipe use the same exit. Selection begins closing immediately and runs the existing async switch concurrently, so cached home totals update during the exit; slow network/sync still completes without inventing balances. The option list is frozen during exit to prevent a height change mid-animation. The global dialog-close animation and generic backdrop listener explicitly exclude this sheet, avoiding a second exit/focus delay. Reduced Motion uses 120/100ms opacity only; keyboard focus returns to the picker. Downward drags from the header or the top of the list follow the finger through direct transforms. Distance/velocity determine dismissal; short and cancelled drags return to rest. Upward motion and an already-scrolled list retain native scrolling, multi-touch cancels the drag, and a claimed drag suppresses its trailing click. Touch events use a conditional non-passive move handler for WKWebView; mouse/pen use pointer capture. A source update keeps the label/options current and preserves focused option when possible.

The microphone grows from 152 to 168px on regular screens, 136 to 150px on short screens and 124 to 136px on very short screens. The existing lens uses stronger accent blends and static depth; its zone, hold-to-record interaction, recording animations and opaque base remain. All colors use existing theme variables. No palette regeneration, third-party UI library, Swift change or server deployment is required.

Validation: 72 app tests; optional browser tools `verify-home-account-picker.cjs`, `verify-stable-surfaces.cjs`, `verify-mic-motion.cjs` and `verify-shared-ui.cjs` with `MONO_PLAYWRIGHT_MODULE`/`MONO_CHROMIUM_PATH`. The picker scenario covers personal/shared choices, private-history preservation, operations scope, held middle/end exit frames, pointer/touch drags and rollback, native long-list scrolling, simultaneous home redraw, Escape/backdrop/focus, four mobile screen sizes, seven themes and Reduce Motion. Verify sheet pacing and microphone emphasis in the next real iPhone build; Chromium is not WKWebView.
